# Checkpoint

> [English](README.en.md) | 简体中文

本地虚拟机集群的**「诊断保命 + 实验辅助」工具** —— 面向在本地用 VMware 搭集群做实验的学生。

它把「快照回滚、健康体检、一键启停、故障诊断、配置分发」连同「HDFS / Hive / YARN 操作」整合到一个界面：**实验前打快照保命，出问题一键体检说人话，崩了回滚还原；每个操作还会显示它实际执行的命令，用着用着就懂了。**

> **操作傻瓜化，但不替学生思考** —— 一键搞定、报错说人话，但只给修复建议、不自动改，保留学习过程。

> 当前版本：**v0.11.1**

---

## 为什么做这个

学大数据的学生常在本地用多台虚拟机搭集群（Hadoop / Hive / Spark / Kerberos…），实验中有几个反复出现的痛点：

1. **环境易崩、难恢复** —— 配错一个参数整个集群起不来，只能重装（几小时）
2. **报错看不懂** —— `Connection refused`、`command not found`…… 新生不知哪错、咋修
3. **操作繁琐** —— 启停集群要记一堆命令、一台台敲
4. **环境不通用** —— 装了 Kerberos 就"专一"了，做别的实验很麻烦

企业级集群管理工具（面向服务器运维）太重，通用开源工具偏 geek，快照工具又只管一件事 —— **没有一个正好适合"本地虚拟机 + 学生实验"这个场景**。Checkpoint 就补这个空：轻量（pywebview，exe 仅 ~18MB）、面向新手（红绿灯 + 人话报错 + 一键）、但只做**诊断与保命**，不替学生思考。

> 文档告诉你"步骤"，本工具解决文档的死角：**出错时帮你查、帮你救**。

## 功能

### 虚拟机 / 快照
- **自动扫描**：读取 VMware 记录，自动发现本机虚拟机（带缓存，秒开）
- **快照管理**：打快照、切换分支（回滚）、删除、**树状视图**、**克隆为独立 VM**
- **集群快照**：给整个集群批量打快照 / 回滚，**支持勾选部分节点**
- **运行状态**：查看运行中的虚拟机，一键启动 / 停止 / 关闭全部
- **自定义备注**：给虚拟机起软件内的显示名（如「主节点」）

### 集群管理
- **集群节点**：配置节点（IP / 凭据 / 角色 / 所属集群），**支持多集群**
- **集群模板**：一键生成标准 N 节点骨架（Hadoop 3 节点 / Hadoop+Kerberos 5 节点）
- **一键启停**：按依赖阶段编排（NTP → KDC → HDFS → YARN → HistoryServer）
- **健康体检**：检查节点在线 / 进程 / 端口 / 系统服务（红绿灯）
- **部署前自检**：Java / hosts / SSH / 时间 / SELinux / 防火墙
- **配置分发**：扫描 master 配置目录，rsync 到从节点（支持节点独立根目录）

### 数据与作业
- **HDFS 操作**：浏览 / 上传 / 下载 / 新建 / 删除 / 重命名 / 搜索（带目录树）
- **Hive 查询**：SQL 编辑器（语法高亮）+ 库表树 + 结果表格
- **表管理 / 数据导入**：浏览 Hive 表、把 HDFS 文件建表导入
- **HBase 浏览**（装了 HBase 才显示）
- **YARN 作业**：列表 / 状态 / 日志 / 终止
- **作业模板**：WordCount / TestDFSIO / TeraSort / Spark，一键运行
- **集群验证**：跑 WordCount 冒烟测试（验证 MapReduce 全链路通不通）
- **部署后验证**：检查 DataNode 是否注册、是否处于安全模式

### Kerberos 环境管理（v0.11.0 新增）
- **配置备份 / 恢复**：把 master 上的关键配置打包存到本地（几 KB、不用关机），随时还原；与 VM 快照互补（快照=整机、要关机；配置备份=文件、在线、能看 diff）
- **变更提醒**：进配置备份页自动检测"哪些配置自上次备份后被改"，建议留还原点
- **Kerberos 配置检测**：13 项静态检查（KDC / realm / keytab 权限与分发 / 各服务 principal / 重启是否生效 / hdfs-yarn 免密…），每项三态（完整 / 半成品 / 缺失 / 无法检测），不假绿
- **一键补免密**：装 Kerberos 后 start-dfs.sh 要用 hdfs/yarn 用户，免密漏配是"起不来"的常见根因——一键补齐
- **一键切换 kerberos ↔ simple**：改配置 + 重启 HDFS/YARN（声明式、命令可见、切换前自动备份）；切 simple 一并撤销 Kerberos 引入的 HTTPS / 安全容器执行器配置
- **配置 diff**：列出当前所有 Kerberos 相关配置项（核心开关 / 附加项），看得见锁在哪

### 工具
- **脱敏诊断包**：一键打包环境信息（去密码、IP 打码），方便求助
- **声明式集群配置**：把集群拓扑导出 / 导入为 JSON（可备份、可分享）
- **配置模板**：core-site / hdfs-site 等标准配置模板
- **结果导出**：体检结果导出为 markdown

### 界面
- **左侧活动栏**：按用途分区（环境 / 数据 / 作业 / 工具 / 设置），切换即换右侧内容
- **对象 + 选项卡**：集群、节点各有独立选项卡（集群：概览 / 节点 / 服务拓扑 / 资源监控 / 快照 / 配置分发；节点：健康 / 服务 / 快照 / 配置 / 终端）
- **底部面板**：输出 / 任务 / 终端，可折叠、可拖拽调高度（仿 VSCode）
- **命令可见**：每个操作会显示**实际执行的命令**（逐条附注释、解释参数），鼠标悬停看用途——用着用着就懂了；可折叠、可复制
- 界面风格主题（仪表盘 / 终端 / 蓝图）、界面缩放、窗口边缘拖拽

### 诊断 / 体验
- **人话报错**：常见错误翻译成「原因 + 修复建议」（24 条规则）
- **VMware 环境管理**：状态灯 + 服务逐个启停 + 启动 VMware
- **关机节点自动跳过**：秒判，不白等超时
- **并发互斥**：操作进行中禁用相关按钮，避免冲突
- **深浅主题**、中英切换、界面动画
- **界面风格主题**：可切换 仪表盘 / 终端 / 蓝图 三种风格
- **界面缩放**：Ctrl + / Ctrl - / Ctrl 0，比例记忆
- **无边框窗口边缘拖拽**：可从窗口边缘拉伸改尺寸
- **检查更新** + 全局异常捕获（写 `error.log`）

## 环境前提

本工具**面向本地虚拟机集群实验**，需要你先具备：

1. **VMware Workstation / Player**（本工具靠它自带的 `vmrun.exe` 管虚拟机）
2. **若干台 Linux 虚拟机**（如 CentOS 7），组成本地集群（如 master / user1 / user2 / ntp / kdc）
3. 各节点**网络互通**、**SSH 可登录**（配置分发还需 master→从节点 **SSH 免密**）

> 没有现成集群？先按教程搭好（或用「集群模板」生成节点骨架），再回来用本工具做**体检 / 启停 / 诊断**。

## 快速上手

1. **打开软件** → 进「环境」域的集群页
2. 点 **＋ 新建集群**（或用 **⊞ 模板**一键生成标准节点）
3. **添加节点**：填 IP / 用户名 / 密码 / 角色（选虚拟机还能自动带出配置）
4. 点 **体检** → 看红绿灯（🟢 正常 / 🟡 部分异常 / 🔴 异常 / ⚪ 关机）
5. 有问题？点 **部署自检** 查环境；启停失败会显示**人话诊断**
6. 实验前先 **打快照**（单台 / 集群），搞崩了一键 **回滚**
7. 想传数据 / 跑查询 / 看作业？切到左侧 **数据** / **作业** 域（HDFS / Hive / YARN）

> 每个操作下方都会显示它执行的命令（可折叠）——**鼠标悬停命令看用途，用着用着就懂命令行了。**

## 使用

### 方式一：安装包（推荐）

1. 下载 `Checkpoint-Setup.exe`
2. 双击，选择安装位置
3. 安装完成后，双击桌面快捷方式运行

**前置要求**：已安装 VMware Workstation / Player（需用到其自带的 `vmrun.exe`）。

### 方式二：从源码运行

```bash
# 1. 安装依赖
pip install pywebview paramiko

# 2. 运行
python app.py
```

## 技术栈

- **pywebview**：Python + 内嵌 WebView 的桌面窗口框架
- **前端**：原生 HTML / CSS / JavaScript（无框架）
- **后端**：Python（VM 操作走 VMware `vmrun` 命令行；节点操作走 `paramiko` SSH）
- **打包**：PyInstaller（独立 exe）+ Inno Setup（安装包）

## 配置文件

程序运行时会在**程序所在目录**生成：

- `settings.json` —— 设置（vmrun 路径 / 语言 / 当前集群等）
- `nodes.json` —— **集群节点**（IP / 凭据 / 角色；⚠ 含明文密码，只存本机）
- `aliases.json` —— 虚拟机的显示名 / 备注
- `vms_cache.json` —— 虚拟机扫描缓存
- `health_cache.json` —— 上次体检结果（重开仍可见）
- `services_state.json` —— 服务启停开关状态
- `error.log` —— 错误日志（若发生异常）
