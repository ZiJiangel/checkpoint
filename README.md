# 集群快照管理器

> [English](README.en.md) | 简体中文

一个用于管理 VMware 虚拟机快照（分支）的桌面小工具。像切换 Git 分支一样，管理虚拟机快照的创建、回滚与记录。

> 当前版本：**v0.3.0**

---

## 功能

- **自动扫描**：读取 VMware 记录，自动发现本机虚拟机（带缓存，秒开）
- **快照管理**：打快照、切换分支（回滚）、删除快照
- **批量操作**：可选多台虚拟机，一次性打同名快照 / 回滚
- **自定义备注**：给虚拟机起软件内的显示名（如「主节点」），不改动虚拟机本身
- **状态圆点**：灰=加载中 / 蓝=存在 / 绿=运行中 / 红=路径失效
- **深浅主题**：一键切换，全窗口联动
- **自绘标题栏**：无边框窗口，自定义标题栏（Windows 上无系统原生标题栏）
- **运行状态**：查看运行中的虚拟机，一键启动 / 停止
- **语言切换**：中 / 英文界面，记忆上次选择
- **集群节点**：配置集群节点（IP / 凭据 / 角色），SSH 连接
- **健康体检**：一键检查各节点在线状态与 Hadoop 进程（红绿灯）
- **检查更新**：一键检查 GitHub 上是否有新版本
- **错误处理**：全局异常捕获，写入 `error.log`，弹窗提示

## 使用

### 方式一：安装包（推荐）

1. 下载 `集群快照管理器-安装包.exe`
2. 双击，选择安装位置
3. 安装完成后，双击桌面快捷方式运行

**前置要求**：已安装 VMware Workstation / Player（需用到其自带的 `vmrun.exe`）。

### 方式二：从源码运行

```bash
# 1. 安装依赖
pip install pywebview

# 2. 运行
python app.py
```

---

## 技术栈

- **pywebview**：Python + 内嵌 WebView 的桌面窗口框架
- **前端**：原生 HTML / CSS / JavaScript（无框架）
- **后端**：Python（调用 VMware 的 `vmrun` 命令行）
- **打包**：PyInstaller（独立 exe）+ Inno Setup（安装包）

## 配置文件

程序运行时会在**程序所在目录**生成：

- `settings.json` —— 设置（vmrun 路径等）
- `aliases.json` —— 虚拟机的显示名 / 备注
- `vms_cache.json` —— 虚拟机扫描缓存
- `error.log` —— 错误日志（若发生异常）
